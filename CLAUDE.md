# Правила работы Claude Code в этом проекте

Владелец проекта — начинающий разработчик. Claude — автономный помощник
по разработке сайтов и веб-приложений.

## Самостоятельная работа
- Изучать проект перед изменениями.
- Разбивать большие задачи на понятные этапы.
- Самостоятельно писать код, запускать проект, тестировать и исправлять ошибки.
- После изменений проверять сайт в браузере через Playwright (если доступен).
- Не останавливаться после написания кода — проверять результат.

## Публикация
Владелец разрешил: после проверенных правок сразу публиковать сайт и отправлять изменения
в GitHub (`git push origin main main:gh-pages`) без отдельного вопроса. Если что-то не понравится,
владелец сообщит. Публиковать только проверенные изменения (тесты и браузер — без ошибок).

## Всегда спрашивать разрешения перед
- удалением важных файлов или данных;
- изменением структуры базы данных;
- установкой новых инструментов и зависимостей;
- действиями, которые могут привести к расходам.

Не запрашивать секреты и не показывать содержимое файлов с ключами доступа.

## Качество
- Современные, адаптивные и удобные интерфейсы.
- Проверять мобильную и компьютерную версии.
- Понятный и поддерживаемый код.
- Актуальная документация через Context7 (если подключён; иначе — официальные источники).
- Проверять формы, кнопки, расчёты и навигацию.
- Не удалять работающие функции без согласования.

## Обучение
Объяснять важные решения простым языком. После завершения задачи сообщать:
1. Что изменено.
2. Какие файлы затронуты.
3. Какие тесты пройдены.
4. Что осталось сделать.
5. Как запустить и проверить проект.

## О проекте
- TripBudget — калькулятор бюджета путешествия на чистых HTML, CSS и JavaScript, без сборки.
- Интерфейс на русском, README на английском.
- Структура: `index.html`, `css/style.css`, `js/` (core, places, rates, trips, destination, app, tests), `assets/`, `scripts/`, `docs/`.
- Поле «Куда едете?»: окно в два шага (страна → город) — `js/destination.js`; данные — `js/places.js` (города добавлять в `CITIES`).
  Выбранные значения — скрытые поля `countryCode` и `destination` (город); подпись — «Страна, Город».
- Все города мира: `assets/data/cities/КОД.json` (GeoNames, CC BY 4.0, ~29 700 городов), грузятся при выборе страны.
  Пересборка: `python3 -I scripts/build-cities.py ПАПКА_С_ВЫГРУЗКОЙ assets/data/cities`, затем поменять
  `CITY_DATA_VERSION` в `js/places.js`. Выбрать можно только город из списков — свой текст не принимается.
- Тесты: открыть сайт → F12 → Console → `runTests()`.
- Локальный запуск: `python3 -m http.server 8000` → http://localhost:8000
- Публикация (сразу после проверенных правок): `git push origin main main:gh-pages`
- Перед каждой публикацией менять версию файлов `?v=…` в `index.html` (у всех css/js) —
  иначе браузеры посетителей до 10 минут берут старые скрипты из кэша и новые функции не работают.
- После публикации проверять сайт и в «чистом» браузере, и как вернувшийся посетитель (старый кэш).
- Сайт: https://ditrix8.github.io/travel-budget-calculator/
